# Low-Channel English-Bangla Inner-Speech EEG Decoding

This repository contains the analysis code associated with the study:

**A Low-Channel Riemannian Framework for Explainable English and Bangla Inner-Speech EEG Decoding**

The study investigates six-class directional inner-speech EEG classification in English and Bangla using a compact 12-channel EEG montage, covariance-based Riemannian tangent-space features, RBF-SVM classification, subject-independent evaluation, ablation analysis, and model explainability.

## EEG Configuration

Sampling frequency: **256 Hz**

EEG channels:

`F3, Fz, F4, FC3, FC4, C3, Cz, C4, CP5, P3, P4, PO7`

Directional classes:

- Back
- Down
- Forward
- Left
- Right
- Up

The English and Bangla datasets are analyzed independently.

## Main Analysis Pipeline

```text
Preprocessed EEG
        ↓
7-s EEG epochs
        ↓
2-s windows with 50% overlap
        ↓
Per-window/channel z-score standardization
        ↓
Oracle Approximating Shrinkage covariance estimation
        ↓
Training-derived Riemannian tangent-space projection
        ↓
78-dimensional tangent-space representation
        ↓
Training-only StandardScaler
        ↓
RBF-SVM (C = 10, gamma = "scale")
        ↓
Window-level predictions
        ↓
Epoch-level majority voting
```

## Repository Files

- `epochwise_eng.py`: primary epoch-position-heldout English classification.
- `epochwise_bangla.py`: primary Bangla classification.
- `loso.py`: strict leave-one-subject-out evaluation.
- `ablation.py`: covariance and feature-representation ablation experiments.
- `xai.py`: channel ablation, regional ablation, permutation importance, SHAP, and related XAI outputs.

If your local filenames differ slightly, rename them consistently or update this README.

## Reproducibility Notes

The main epoch-heldout and LOSO procedures are deterministic under the specified split logic.

For stochastic explainability procedures, including permutation importance and SHAP sampling, the XAI pipeline uses `SEED = 42`.

The main RBF-SVM classifier uses:

```python
kernel="rbf"
C=10
gamma="scale"
decision_function_shape="ovr"
```

Overlapping windows from one EEG epoch are not treated as independent final observations. Window-level predictions are aggregated into one epoch-level prediction by majority voting.

## Incomplete Recordings

The analysis uses the number of complete epochs actually available in each preprocessed EEG file. Missing epochs are not imputed or duplicated. If metadata and complete CSV-derived epoch counts differ, the complete CSV-derived count is used by the analysis scripts where applicable.
