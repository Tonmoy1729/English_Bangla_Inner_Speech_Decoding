# Data Access

The EEG dataset associated with this repository is maintained separately from the source code.

## Dataset

**Low-Channel English-Bangla Inner Speech Raw EEG Dataset**

Authors:

- Tonmoy Paul
- Dip Muhuri
- Md. Joynul Abedin

Mendeley Data, Version 1

Provisional DOI: **10.17632/vtntshd99d.1**

The raw and preprocessed EEG data are not included directly in this GitHub repository.

During peer review, confidential access is provided through the journal submission materials. The dataset is intended to be released publicly through Mendeley Data upon acceptance/publication of the associated article.

After obtaining the data, copy `config.example.py` to `config.py` and set `DATA_ROOT` to the local dataset location.
